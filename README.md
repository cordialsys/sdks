# Cordial Treasury SDKs

Client SDKs for the Cordial Treasury API.

## SDKs

- [Go SDK](go/README.md): `github.com/cordialsys/sdk-go`
- [Rust SDK](rust/README.md): `cordial-treasury`
- [TypeScript SDK](typescript/README.md): `@cordialsys/treasury-sdk`

The examples in each SDK README use the hosted Treasury API at `https://treasury.cordialapis.com/`.
